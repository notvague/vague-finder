# Context 검색 최종 검증 기록 — 2026-10-06

작품 사용 장면·제작 비화·방송 일화 같은 단서를 QueryAnalyzer에서 분리하고, 나무위키 사실 Dense 검색과 곡 프로필 Sparse 검색을 하나의 Context 순위로 합칩니다. 이 후보를 기존 Text/Image/Audio 후보 절단 전에 합류시킵니다. Dense의 관련 사실을 확인했을 때만 사실 문장과 출처를 응답에 표시합니다.

이 문서는 완료된 실험과 실제 HTTP 기록의 요약입니다. 이전 API 보완 문서의 실패 기록 이후 **`passed_api_smoke`, `api_verified=true`가 확인된 최종 상태**를 기록합니다. 코드 구현·전체 코퍼스 측정·설정 적용·현재 데스크탑 API 검증을 완료했습니다. 배포 환경 전체 또는 모든 사용자 문장의 정확성을 보증하는 문서는 아닙니다.

## 비교 조건과 분모

- 같은 완성 코퍼스, 각 질의의 **동일 QueryAnalyzer 분석 결과**로 Context OFF/ON을 비교했습니다. 양 조건의 후보 폭 30, 화면 결과 10, **rerank OFF**입니다. 고정 설정에서 파라미터를 다시 선택하지 않았습니다.
- dev 74개 + test 32개 + 작성 질의셋 60개 = **166개 질의 전체**를 보고했습니다. 추가 재분석 10건과 실제 API 요청 18건은 독립 질의 수에 합산하지 않습니다.
- Context 효과 표의 분모는 배경지식이 필요한 순수·혼합 질의입니다. 무관한 대조 질의 3/1/6개를 효과 분모에서 제외하고 별도 회귀 검사했습니다. 기존 검색 질의는 53/23/18개입니다. 모든 정답이 현재 인덱스에 있고, 미색인 정답을 분모에서 제외하지 않았습니다.
- `Candidate@30`은 30개 후보 중 정답이 하나라도 있는 질의 비율, `Hit@10`은 화면 10개 중 정답이 있는 비율, `MRR@10`은 첫 정답 순위의 역수 평균(미진입은 0)입니다. 여러 정답의 평균 recall과는 구분합니다.

## 실제 경로와 근거 검증

- 이미지 필수 질의: dev **9/9**, test **3/3**, 작성셋 **6/6**에서 OFF/ON 모두 이미지 임베딩·DB 조회를 확인했습니다. 작성셋 오디오 필수 **6/6**도 OFF/ON 모두 확인했습니다. 단순히 가중치가 양수인 것을 실행 증거로 삼지 않았습니다.
- 주 평가에서 표시된 사실 **28건(9+5+14)**은 모두 등록된 관련 사실 라벨과 일치했습니다. 미검토 0건입니다. 재분석 10건에서 표시된 2건도 미검토 0건입니다. 사실 라벨 대조는 저장된 사실의 질의 관련성을 검사하며, 문서 자체의 진실성을 독립적으로 인증하지 않습니다.
- 정답이 Top-10에 있더라도 관련 사실 확인이 부족하면 근거는 표시하지 않습니다. Sparse 프로필 일치, 같은 작품 이름 또는 같은 장소라는 이유만으로 사건 근거를 표시하지 않습니다.
- 실제 HTTP **18/18건 통과**: 기존 5건 + 등록된 이미지 6건 + 오디오 6건 + 첫 5개 후보 거절 후 보충 1건입니다. 원래 질의로 새 분석을 실행하고, 응답 `X-Request-Id`와 같은 원문·상태 200의 서버 시간 기록을 대조했습니다. 리랭킹 실행 0건, 중복 후보 없음, 30개 후보 보충·거절 ID 제외·정식 메타데이터·근거 응답을 확인했습니다.
- API의 이미지 실행 **7건**, Top-10 양수 기여 **7건**; 오디오 실행 **8건**, Top-10 양수 기여 **2건**입니다. 혼합 질의에서 실행된 경로가 최종 Top-10에 남지 않을 수 있으므로 둘을 구분했습니다. 이미지·오디오 단독 검색 정확도나 대규모 부하 성능으로 확대 해석하지 않습니다.
- HTTP 재분석에서도 필수 두 Context 사례는 정답 Candidate@30에 진입했습니다. 그중 하나는 Top-10에 없었습니다. 첫 5곡 거절 후 30개 후보가 보충됐고 해당 정답은 Top-10에 진입했습니다. 원문/곡 정보는 팀 내부 자료에서 확인합니다.
