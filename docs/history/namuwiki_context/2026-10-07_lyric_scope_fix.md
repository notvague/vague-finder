# 가사 인용과 오디오·이미지 단서 구분 수정

이번 피드백의 dev 74문항과 test 32문항은 완료됐고, 두 보고서 모두 `status=passed`, `violations=[]`다. 중단 지점은 새로운 60문항의 분석 준비 중 `fresh047`이다. 가사 인용 안의 ‘따뜻한’을 오디오 분위기 단서로 읽어 정상적인 빈 `audio_english_query`를 거절했다. Gemini 서비스 장애로 확인된 문제가 아니다.

아래 수치는 사용자가 보낸 `context_media_scope_20261006_201909_240594_feedback_gwx8t7fi.zip`의 실제 검색 보고서에서 가져왔다. 리랭킹 OFF, 같은 분석을 사용한 Context OFF/ON 비교다. 이번 가사 수정 이후의 새 측정값은 아니다.

| 평가 | Candidate@30 OFF → ON | Hit@10 OFF → ON |
|---|---|---|
| dev 전체 74문항 | 55/74 → 65/74 | 45/74 → 52/74 |
| dev Context 21문항 | 9/21 → 18/21 | 9/21 → 16/21 |
| dev 기존 회귀 53문항 | 46/53 → 47/53 | 36/53 → 36/53 |
| test 전체 32문항 | 26/32 → 26/32 | 21/32 → 23/32 |
| test Context 9문항 | 9/9 → 9/9 | 7/9 → 9/9 |
| test 기존 회귀 23문항 | 17/23 → 17/23 | 14/23 → 14/23 |

Candidate@30·Hit@10·MRR@10 손실 질의는 두 분할 모두 없다. 독립 질의 60문항의 검색 비교와 반복 분석은 아직 완료되지 않았다. 이미 확인한 dev/test 및 60문항의 재측정은 새로운 블라인드 표본의 성능 증명이 아니다.

## 수정 범위

`src/retrieval/modality_queries.py`의 단서 판정에서만 명시적으로 가사에 속하는 인용 구간을 공백 처리한다. 사용자의 원문, Text 검색문, 추출된 가사 단서는 보존한다. 문자열 길이와 줄바꿈 위치를 유지하므로 Context에서 사용하는 앨범 표지의 위치도 어긋나지 않는다.

- 작은·큰따옴표, 한국어 인용 부호, 줄바꿈, 연결된 가사 인용을 검사한다.
- 가사라고 명시한 따옴표 없는 구절과 `가사:` 행도 검사한다.
- 인용문 밖의 피아노 반주, 보컬, 표지 색감은 그대로 사용한다.
- 일반적인 ‘따뜻한 목소리’ 인용과 실제 후렴의 악기 설명은 가사로 지우지 않는다.
- 가사만 보고 추론한 가창 인원 등은 기존 메타데이터 검증을 통해 제거한다.
- 실제 소리·표지 단서가 있는데 해당 영어 검색문이 없는 경우의 엄격한 검증은 유지한다.

질의 ID나 특정 가수·곡으로 우회하지 않는다. 테스트의 가사 문구는 만든 예시다. QueryAnalyzer 프롬프트, 검색 순위 로직, Qdrant, 평가 가중치와 정답을 바꾸지 않는다.

## 적용과 전체 검증

프로젝트 루트에서 ZIP을 풀고 다음을 실행한다.

```powershell
.\experiments\namuwiki\run_context_lyric_scope_fix.ps1 -Mode All
```

현재 소스와 패키지의 내용이 일치하는지 확인한 뒤 원본을 백업하고 수정한다. 보내준 프로젝트와 다른 소스이면 덮어쓰지 않고 중단한다. 백업과 보고서는 새 `artifacts/context_lyric_scope_...` 폴더에 저장한다. `.env`를 편집하지 않는다. 임베딩 재생성이나 Qdrant 재적재도 필요 없다.

자동으로 backend 중지 → 적용·백업 → 이미지 빌드 → Context·Qdrant·재질문·설명·가사 회귀 테스트 → 가사/음향/표지 7가지 비교 출력 → 실행 설정 확인 → 새 분석을 사용한 dev/test/60문항 및 반복 분석 평가 → 조건 통과 시 실제 HTTP API 검사 → backend 복구를 수행한다. 공용 MongoDB는 중지하지 않는다.

이전 분석 캐시를 이번 분석으로 재사용하지 않는다. 기본 실행은 매번 새 출력 폴더를 만들므로 기존 보고서를 삭제할 필요가 없다. `-Resume`은 같은 코드·설정·입력으로 생성한 새 실행에만 사용한다.

코드 테스트만 실행하려면 `-Mode Tests`를 사용한다. 이 모드는 성능·API 완료를 의미하지 않는다.
