검색 근거에서 확인되지 않은 MV 장면을 사실처럼 말하는 문제를 수정해줘.
`docs/plans/grounded-search-explanations-plan.md`를 먼저 읽고 현재 코드와 대조한 뒤 구현·검증해줘.

사용자 사례:
- 질의: `남자 인디 노래인데 뮤비에 의자가 하늘에 떠있는 장면이 있어`
- 결과 1위: BOYNEXTDOOR - Upside Down, song_id=602193305
- 근거 마지막 문장: `뮤직비디오에 옥상에서 의자를 던지는 장면이 나온다`
- 사용자는 실제로 그런 장면이 없다고 확인했다.

이미 확인한 내용:
- 현재 로컬 곡 레코드와 그 레코드로 재구성한 리랭커 입력에는 의자 장면이 없다.
- 가사 요약에는 옥상이 있지만 MV 장면 근거가 아니다.
- visual_imagery는 수집 프롬프트가 창작하도록 만든 필드다. 현재 listwise 입력에는 이 필드 자체가 포함되지는 않는다.
- 리랭커는 일반 지식 사용을 허용하고 자유 서술 reason을 만든다.
- reason은 사실 검증 없이 model_notes로 API와 근거 패널에 표시된다. 미검증 경고는 이미 있다.
- Search grounding·희소 사실 검증은 기본 꺼짐이다. _rare_fact_reason은 이 예시를 감지하지도 못한다.
- 문제 문장을 넣은 모의 응답이 파서와 API 출력까지 통과하는 것은 확인했다.
- 당시 실제 응답 원문·후보 순서는 확보하지 못했다. 이 허구 때문에 1위가 됐다고 단정하지 마.

1. 사용자에게 보여주는 설명을 고쳐줘.
- 자유 생성 model_notes는 일반 API와 화면의 근거에서 제외해줘.
- 파서와 내부 진단 기록에는 원문을 보존해줘. 경고만 추가하거나 CSS로 숨기는 것으로 끝내지 마.
- 기존 실행 기록 기반 summary, 검색 경로·순위 변화, 실제 가사 인용은 유지해줘.
- 호환성을 위해 공개 model_notes를 빈 배열로 남기는 방식은 가능해.
- MV 장면 자료가 없는 경우에는 구조화된 상태와 고정 문구로 그 점을 안내해줘.
- 이 설명 수정만 적용했을 때 결과 ID·순서·점수는 같아야 한다.

2. 자료 없이 구체적인 MV 장면을 추측하는 재정렬도 막아줘.
- 구체적 MV 장면 질의인데 장면을 평가할 출처 자료가 리랭커에 없으면,
  Gemini 재정렬을 생략하고 기존 검색·답변 보정·거절 제외가 반영된 후보 순서를 유지해줘.
- 단순 MV 단어 포함, 감성 묘사, 가사 인용, 부정·모름 표현까지 일괄 차단하지 마.
- 서버가 가진 근거 자료로 판단해줘. 모델의 confidence나 verified 선언은 근거가 아니다.
- 가사, 상상 이미지, 표지, 단순 YouTube URL을 MV 장면의 증거로 취급하지 마.
- 생략은 실패와 구분해 기록하고, 실행하지 않은 리랭킹의 점수·이유·순위 이동을 표시하지 마.
- 서비스와 evaluate_search_accuracy 등 평가 경로가 같은 정책을 쓰게 해줘.
- 기존 가사 보호, 재질문 답변 보정, 이미지 질의 정책, 다른 리랭커 백엔드는 점검해 보존해줘.
- 전체 검색에서 LLM을 끄거나 Search grounding·희소 검증을 전역으로 켜지는 마.

3. 테스트와 결과를 남겨줘.
- 높은 confidence의 허구 응답도 일반 API·UI에 노출되지 않는지 검증.
- 문제 문장 외의 임의의 허구 주장도 동일하게 처리하는지 검증.
- MV 표현 변형, 비대상 반례, fallback·prior_analysis, 답변 보정 순서 유지 검증.
- 모델 호출을 금지한 테스트로 MV 보호 경로의 실제 호출 생략을 검증.
- 기존 가사 근거·실행 기록은 유지하고 과거 model_notes가 새 결과에 남지 않는지 검증.
- 계획서의 관련 테스트와 전체 pytest를 실행해줘.
- 순위 정책은 고정 분석·후보·설정으로 영향받는 dev와 대표 비대상 질의를 비교해줘.
  비대상 프롬프트까지 바꾸면 기존 dev 116건의 회귀 측정 범위로 넓혀줘.
- 모델·실제 DB를 쓴 검증과 모의 검증을 구분하고, 미수행 항목은 명시해줘. 봉인 test는 열지 마.

Upside Down을 차단하거나 무조건 1위에서 내리는 수정은 하지 마.
자료 없음은 장면이 없다는 증거가 아니고, 재정렬을 생략해도 같은 곡이 상위에 남을 수 있어.
이번 완료 기준은 허구 장면을 확인된 근거로 보여주지 않고, 자료 없는 MV 추측으로 추가 재정렬하지 않는 거야.

크롤링·영상 분석·코퍼스 수정·색인 재생성은 이번 범위에 넣지 마.
이미 병합한 재질문 작업과 연도 휠·유명도 작업도 건드리지 마.
커밋·푸시·PR 생성은 하지 말고, 변경 파일·사례 결과·테스트·품질 영향·남은 한계를 보고해줘.
