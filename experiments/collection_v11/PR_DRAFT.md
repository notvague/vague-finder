- AI로 다듬은 질의는 `ai_used`로 따로 둔다. 일부러 틀린 단서를 넣는 질의(v10 `misinformation`)는 받지 않는다. `general` 갈래에는 유형 할당이 없다.
- 보관자 폴더가 Git 작업 트리·/tmp 안이면 도구가 거부한다.
