켰을 때만 드러나는 결함을 고쳤다. 기본 OFF 동작은 바뀌지 않는다. 자세한 표는 `RUN_INFO.md` §11.

- **포기한 요청의 호출 차단**: 해석 풀에서 줄을 선 작업이 요청 시간 초과 뒤에 Vertex를 부르던 문제를 막았다. 시간 초과 때 대기 작업을 취소하고, 작업은 시작할 때 마감을 보고 지났으면 부르지 않는다(`failed:deadline_before_call`).
- **흔한 별칭**: 해석기가 별칭으로 "드라마" 같은 일반어를 내면 맞는 작품까지 버리던 문제를 고쳤다. 명시·부정·중복 검사는 형식을 통과한 이름·별칭에만 적용한다.
- **비부정 활용**: "아니면·아니라도·말고도·아닌가" 등은 부정으로 읽지 않는다. "아님"은 부정으로 둔다(남은 한계).
- 사소: Vertex 클라이언트 재사용(호출별 제한은 요청 `http_options`), 부정 구절은 어절 경계에서만, 2턴 질의는 해석 호출 2회로 비용 산정.
