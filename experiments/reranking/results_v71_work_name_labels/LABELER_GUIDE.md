# 작품 의도 라벨 안내

노래를 찾는 사람이 쓴 질의 22개가 있다. 질의마다 **이 사람이 어떤 작품(드라마·영화·예능·경연 프로그램·애니메이션 등)을 떠올리며 썼는지** 판단해 적어 주세요.

- 이 작업은 검색 결과를 채점하는 일이 아니다. 노래가 아니라 **작품**을 판단한다.
- 정답은 없다. 질의만으로 정할 수 없으면 "판단불가"가 올바른 답이다. 억지로 하나를 고르지 않는다.

## 받은 파일

- `work_label_sheet_*.csv` — 항목 번호(`L01`~`L22`)와 질의 원문이 들어 있다. 엑셀이나 구글 시트에서 열어 오른쪽 칸을 채운다.
- 이 안내문.

`item_no`·`query` 칸은 고치지 않는다. 저장은 CSV(UTF-8)로 한다. 다른 형식이면 받은 사람에게 그대로 보내도 된다.

## 하지 말 것

- 우리 프로젝트 저장소·평가 자료·실험 결과·PR·검색 화면에서 이 질의를 찾아보지 않는다. 같은 질의와 정답이 그곳에 있다.
- 노래부터 찾아서(예: "OO 드라마 OST 남자 발라드" 검색으로 곡을 찾은 뒤) 그 곡이 쓰인 작품을 답으로 적지 않는다. 질의 문장이 가리키는 작품을 적는다.
- 다른 라벨러와 답을 맞춰 보지 않는다. 끝나고 받은 사람에게만 보낸다.

## 해도 되는 것

- **작품**을 확인하는 검색(줄거리·방영 연도·출연자·시즌)은 해도 된다. 했으면 `external_check=yes`로 표시하고 출처를 적는다.
- 확인한 작품 내용과 질의 속 기억이 일부 다르면 `memory_mismatch`에 무엇이 다른지 적는다(연도·줄거리·인물 등).
- 작품이 **있다는 것**과 **이 사람이 그 작품을 뜻했다는 것**은 다르다. 존재만 확인됐고 질의와 맞는지 자신이 없으면 확신을 낮추고 이유를 적는다.

## 칸 설명

| 칸 | 적는 것 |
|---|---|
| `judgment_status` | **단일** · **복수** · **작품아님** · **판단불가** 중 하나(정확히 이 글자) |
| `intended_work` | 단일이면 작품명 1개. 복수면 가장 그럴듯한 것을 적어도 되고 비워도 된다. 작품아님·판단불가면 비운다 |
| `possible_works` | 복수면 가능한 작품 2개 이상을 `;`로 구분. 단일이면 비운다 |
| `work_type` | 드라마 · 영화 · 예능 · 경연/오디션 · 애니메이션 · 기타(무엇인지) |
| `work_identifier` | 동명 작품·시즌을 가를 정보(연도, 시즌, 방송사·플랫폼). 필요 없으면 비운다 |
| `query_phrase` | 판단 근거가 된 질의 속 구절을 그대로 옮긴다(여러 개면 `;`) |
| `external_check` | yes · no — 외부 자료를 찾아봤는가 |
| `sources` | 찾아봤다면 출처(사이트 이름이나 주소) |
| `memory_mismatch` | 확인 자료와 질의의 기억이 다른 점(없으면 비움) |
| `confidence` | 높음 · 중간 · 낮음 |
| `open_questions` | 남는 의문. 판단불가면 왜 정할 수 없는지 한 줄 |
| `labeler_id` · `labeled_at` | 이니셜, 날짜(`2026-10-20` 또는 `2026-10-20 14:30`) |
| `saw_model_output_before` | yes · no · unsure — 이 질의에 대해 프로그램이 낸 작품명을 본 적이 있는가 |
| `saw_answer_song_before` | yes · no · unsure — 이 질의의 정답 곡을 알고 있었는가(질의를 직접 썼거나 평가 자료를 본 경우) |
| `saw_experiment_results_before` | yes · no · unsure — 이 질의의 검색 순위·실험 결과를 본 적이 있는가 |
| `saw_v67_work_list_before` | yes · no · unsure — 저장소 v67 진단 자료(작품명 목록·실패 검토표)를 본 적이 있는가 |
| `notes` | 그 밖의 메모 |

`saw_*` 칸은 솔직하게 적는다. 이미 봤다고 해서 라벨을 버리지 않는다. 분석할 때 "독립 라벨"과 따로 센다.

## 판단 상태 고르기

- **단일**: 질의 문장으로 작품 하나가 정해진다.
- **복수**: 둘 이상의 작품이 똑같이 맞는다.
- **작품아님**: 질의가 작품을 가리키지 않는다.
- **판단불가**: 작품을 가리키는 것 같지만 이 문장만으로는 정할 수 없다.

끝나면 파일을 받은 사람에게 보낸다. 보낸 뒤에는 고치지 않는다. 고칠 것이 생기면 고친 이유와 함께 새 파일로 보낸다(처음 파일은 그대로 남긴다).
