- **첫 실행 권고: ① B의 실제 Vertex 평가.** 구현이 없고 오프라인 근거(+5/−0, 2회 결정적, 조회 실제 생략)가 있으며 CLAP 로드·임베딩 비용이 사라진다. **이어서 ②를 주 개발 후보로 검토한다** — 고칠 방법 단위로 가장 큰 묶음(후보 밖 14)이고, 작품명 수동 주입 진단에서 후보 밖 9질의 중 6질의가 후보에 들었다.
