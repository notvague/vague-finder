## 1. 결론: 지금은 실제 리랭킹 평가를 하지 않는다

결과 전에 고정한 기준(RUN_INFO §5-3) 중 G1(후보 순증 ≥ +1)과 G4(짝 지연 증가 ≤ 50ms)가 거짓이다. 후보 회수는 125 → 124(얻음 0 · 잃음 t044)였고, 정답이 보조 목록에 든 질의는 0건이었다. 그런데도 전송 프롬프트는 109질의(기존 성공 68)에서 바뀐다. 실제 평가를 하면 dev 176 기준 약 664회 · v75 실측으로 약 $3.1을 써서 **이득 근거가 없는 입력 변화**의 결말만 재게 된다. 그 비용에 맞는 질문이 아니다.

2. 또는 **새 자료 `policy_dev`**(COLLECTION_REQUEST.md)에서 이번 판(`desc_residual_v1`)의 후보 단계 결과가 dev와 다를 때(질의의 일반어가 소개 원문과 같은 낱말로 맞는 경우가 실제 분포에서 흔한지).
