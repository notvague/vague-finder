# v0.24 — 3,010곡에서 CE 20곡 채점 제한을 다시 확인한다 · 2026-10-01

**결과: 20곡 제한을 유지한다(팀 결정 2026-10-01).** 같은 후보 30곡을 놓고 앞 20곡만 채점한 것(v22)과 30곡을 다
채점한 것(이 폴더)을 비교했다. 엄격 지표는 20곡이 같거나 낫고(dev q308 1위 vs 2위, 나머지 동일), CE 시간은
2,855 → 1,839ms(−36%)다. 후보 21~30위에 있는 정답은 30곡을 다 채점해도 top-10에 오르지 못했다.

952곡에서 낸 결론(`results_v21_ce_topn`)을 3,010곡에 그대로 가져올 수 없어서 다시 쟀다 — 곡이 늘면서
정답이 후보 21~30위에 있는 질의가 dev 5 · test 2건이 됐다.

**20곡 제한은 확장 지표에서도 잃는 것이 없다.**

### 20곡 제한이 막는 것 — 21위 이하의 승격

30곡 채점에서 후보 21위 이하 곡이 top-10에 오른 경우:

| | 질의 (후보 순위 → 최종 순위) |
|---|---|
| dev | q215 (24 → 6) · q219 (23 → 5, 25 → 8) · q308 (22 → **1**) · m104 (22 → 4) |
| test | q214 (22 → 7) · q305 (22 → 6) |

952곡에서는 test 2건(q214·q305)만 있었고 dev는 0건이었다. 3,010곡에서는 dev에도 생겼다. 이 승격이 정답(원래 타깃·허용 정답)을
올린 경우는 없다. 오히려 q308에서는 승격된 곡(허용 정답 아님 — 확정 조건인
가사가 불충족)이 정답을 1위에서 밀어냈다. 20곡 제한에서 q308 정답이 1위인 것은 그 때문이다.

### 후보 21~30위의 정답

| | 질의 (후보 순위) | 30곡 채점 최종 | 20곡 채점 최종 |
|---|---|---|---|
| dev | q316 (30) · m303 (23) · c602 (24) · c607 (22) · c705 (27) | 모두 top-10 밖 | 모두 top-10 밖 |
| test | q102 (21) · q214 (23) | 모두 top-10 밖 | 모두 top-10 밖 |

CE가 이 정답들을 채점해도 top-10까지 올리지 못한다. 20곡 제한이 잃는 정답은 이번 측정에서 없다.
