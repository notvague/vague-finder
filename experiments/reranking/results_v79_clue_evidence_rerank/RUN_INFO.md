| 구성 | 스위치 | 내용 |
|---|---|---|

## 3. 판정 기준

B가 A1·A2 **둘 다**와 비교해 아래를 모두 만족하면 "채택 후보"다. dev만의 결과이므로 그래도 기본값을 켜지 않고 새 자료 평가로 넘긴다.

| 기준 | 내용 |
|---|---|
| S0 유효성 | 네 실행 모두 리랭킹 failed 0(있으면 그 실행은 비교에서 빼고 판정 보류) |
| S1 Hit@10 | B1·B2 모두 A1·A2 이상이고, 적어도 한 쌍에서 늘어남 |
| S2 손실 | 양쪽 B에서 A 양쪽의 성공 질의를 잃는 질의가 얻는 질의보다 적음 |
| S3 상위 순위 | Hit@1과 MRR이 A 평균보다 낮지 않음(v75에서 Hit@10만 오른 소리 생략을 보류한 기준과 같다) |
| S4 단서 충족 | 상위 10곡의 단서 충족률이 B 양쪽에서 A 양쪽보다 높음 |

같은 구성 반복의 차이(A1↔A2, B1↔B2)보다 작은 A↔B 차이는 효과로 읽지 않는다. 고정된 오차 범위를 쓰지 않는다.

**단서 충족률**은 질의마다 상위 10곡에서 `clue_evidence_for_rerank`가 found·partial로 판정한 단서 비율의 평균이다. B가 그 판정을 입력으로 받으므로 **B에 유리한 지표**다. 단독 근거로 쓰지 않고, 정답 순위가 나빠졌는데 이 값만 오르면 나쁜 신호로 읽는다.

## 4. 동의어 확장 후보 결과와 구성 C 추가 (실제 호출 전, 2026-11-02)

모델 호출 없이 잰 후보 변화(가사 스냅샷·Context 정상, 경로 실패 0): 후보 회수 125 → 126, 얻음 `t100`, 잃음 0. sparse 입력이 바뀌는 질의 12건 중 후보 목록이 달라진 질의 9건이고 그 밖의 질의는 달라지지 않았다. 정답 후보 순위 변화는 q210 12→3 · n006 7→2 · t083 3→1(오름), q215 11→19 · c707 18→20(내림).

§1 조건을 통과했으므로 구성 C를 추가한다. **C = B + `CLUE_SPARSE_SYNONYMS=1`.** 순서는 A1 → B1 → B2 → A2 → C1 → C2다. 한도가 먼저 차면 C가 빠져도 A/B 비교는 완결된다.

- **C 판정:** B와 비교한다. 후보가 달라진 9건에서 Hit@10을 얻고 잃은 수를 본다. 나머지 167건은 입력이 B와 같으므로 B↔C 차이를 **출력 변동**으로 읽는다.
- 동의어 확장은 B의 판정과 묶어 채택하지 않는다. A/B 판정은 §3 그대로다.

- **B 프롬프트 결함:** B1 v09에서 `n017`이 재시도 3회 모두 무효 응답으로 폴백해 안전장치가 멈췄다. 응답 원문을 보니 모델이 `id` 자리에 `retrieval_rank`(20, 23, 22 …)를 넣었다. 같은 질의가 A1에서는 성공했으므로 긴 입력이 일으킨 혼동으로 본다. 파서가 숫자를 순위로 바꿔 끼우지 않고, 규칙 11에 "id를 그대로 옮기고 retrieval_rank는 id가 아니다"를 더했다. 진단 호출에서 `n017`은 1회로 성공했다.

- 이 결함이 B에만 나타난 것은 **입력을 늘리면 모델 출력 형식도 흔들릴 수 있다**는 근거다. 다른 질의의 무효 응답 재시도 수를 결과에서 함께 본다.

## 7. C를 D로 바꾸는 규칙 (A2 결과를 보기 전, 2026-11-02 23:08)

B1·B2는 Hit@10 119로 질의까지 같았고 A1은 122다. A2가 나오기 전에 다음을 정한다.

- §3 판정이 채택 후보가 아니면 C(B + 동의어)를 재지 않는다. 대신 **D = A + `CLUE_SPARSE_SYNONYMS=1`** 을 D1·D2로 잰다. 탈락한 입력 위에서 동의어를 재면 쓸 곳이 없기 때문이다.
- §3 판정이 채택 후보이면 원래대로 C를 잰다.
- **D 판정:** 후보가 달라지는 9건에서 D1·D2의 Hit@10 얻음·잃음을 A1·A2와 비교한다. 나머지 167건은 입력이 A와 같으므로 차이를 출력 변동으로 읽는다. 얻음이 잃음보다 많고 Hit@1·MRR이 A 평균보다 낮지 않으면 채택 후보다.

## 9. 3단계 단서별 검색 — 후보 변화만 (모델 호출 없음, 결과 보기 전 작성)
