## 1. 조건

- 같은 코드·질의로 OFF 서버와 ON 서버를 차례로 띄워 잰다. 기동마다 예열을 끝낸 뒤 요청한다.

- 요청 모양은 화면과 같다(`top_k` 15 · `candidate_k` 30 · `explain` · `defer_clarify`).
- 로컬 Qdrant 색인 복사본 · 피드백 끔 · 가사는 운영과 같은 Mongo 읽기.
- 해석 기록은 HTTP 응답에 없으므로 측정 프로세스 안에서만 받아 적는다.

## 5. 오디오 경로 제외 구성 확인 (2026-11-03, 호출 전 작성)

사용자 결정: 1위 정확도가 조금 낮아져도 10위 안에 드는 쪽을 택해 오디오 경로를 뺀다(v75: Hit@10 121 → 123, Hit@1 83 → 78). §4는 오디오를 켠 상태로 쟀으므로, 작품명 ON · `AUDIO_FUSION_SCALE=0`을 같은 질의·같은 조건으로 잰다. 이 확인은 품질 비교가 아니다.

**기준:** H1·H2·H3·H5는 §3과 같다. H4는 ON 최대 30초 이하, 판정 통과 질의가 OFF 대비 5초 이하다. 한도는 §3 장부에 누적한다.

**결과: 통과.** 10건 모두 200, 분석 폴백 0, 리랭킹 실패 0, 판정 통과 6건 시간 초과·오류 0, 최대 10.24초. 판정 통과 질의의 OFF 대비 중앙값 +1.16초. 별칭까지 16개 이름을 저장 응답의 요약·단서 대조·보정 설명·경로·안내와 대조해 새로 나타난 이름 0(작품명을 넣은 복사본으로 검사가 잡는 것을 확인). 판정은 `analyze_noaudio.py`, 결과는 `summary_on_noaudio.json`. 누적 비용 $0.2154.
