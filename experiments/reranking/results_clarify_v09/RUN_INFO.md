## 새 위험 — 맞는 답이 정답을 Top-10 밖으로 밀어낸다 (listwise에서만)

`reject_only`(답 없음)에서는 Top-10 안이던 정답이 `oracle:*`(맞는 답)에서 밖으로 빠진 경우를 셌다(`compare_clarify.py`).

| | CE dev · test | listwise dev · test |
|---|---|---|
| 건수 | 0 · 0 | **4 · 0** — m402 ×3(성별·편성·장르), c603 ×1(편성) |

- **m402**(분석: 성별 남성 · 장르 발라드, 편성·시기 없음): 답 없는 호출(`reject_only` · `skip` · `flow:reject`)에서는 후보 7위를 지켰는데, `oracle:vocal_gender`(남성) · `oracle:genre`(발라드) · `oracle:type`(솔로) · `rule:oracle` · `flow:oracle` 2턴(발라드)에서 후보 7위 → Top-10 밖으로 빠졌다.
  `oracle:release_era`(2000년대)는 반대로 3위로 올렸고, `flow:oracle` 3턴에 두 번째 답(남성)까지 넣자 1위가 됐다 — 2턴에 찾을 곡을 3턴에야 찾았다.
- **c603**(분석: 성별 남성, 장르·편성 없음): `oracle:type`(솔로)에서 후보 14위 · Top-10 밖. `oracle:vocal_gender`(남성)는 4위 유지, `oracle:genre`는 1위.
- 손실 4건을 답의 성격으로 나누면 둘로 갈린다.

  | 답의 성격 | 잃은 경우 | 반례 |
  |---|---|---|
  | 원래 질의 분석과 **같은 값**을 확인해 준 답 | m402 남성 · m402 발라드 (2) | c603 남성 → 4위 유지 |
  | 질의에 **없던** 새 정보 | m402 솔로 · c603 솔로 (2) | m402 2000년대 → 3위로 상승 |

- 가설 둘(미검증). ① `gemini_listwise_reranker._corrections_block`이 확인용 답도 "more reliable than the original query"로 감싸 넘겨 모델이 일반 속성(남성 발라드)을 과하게 따르고 곡을 구별하는 단서를 놓친다 — 2건을 설명하고 c603 남성이 반례다.
  ② '솔로' 답 두 건이 모두 손실이라 type 슬롯 문구("artist type (solo/group/duo/band)") 자체가 원인일 수 있다 — 나머지 2건.
  고치는 후보: 원래 분석과 같은 값의 답은 블록에서 빼거나 "확인됨"으로만 표시(①), type 슬롯 표현을 바꿔 보기(②). m402 · c603 두 질의로 먼저 잰다.

## 읽는 법

- **재질문의 몫이 "후보 안 순서 바꾸기"에서 "후보 밖 정답을 재검색으로 끌어오기"로 옮겨 갔다.** listwise가 후보 안의 정답은 첫 검색에서 대부분 Top-10에 올리므로 남는 개입 대상은 후보 밖이 대부분이다(dev 26개 대화 중 18개, test 6개 중 5개가 두 번 거절해도 후보 밖). 답변은 후보 안에서만 작용하므로 거기에 닿지 않는다.
- **답변의 효과 자체는 CE 때와 같다.** 전체 기준의 "이득·손해 감소"는 재질문까지 가는 질의가 줄어서 생긴 산술이다. 리랭커가 틀린 답에 강해졌다는 근거는 없다 — 오히려 맞는 답에 흔들리는 새 위험이 있다.
- **거절 뒤 재검색(경로 40)은 리랭커와 무관하게 돕는다.** 다만 건수로는 6.25 → 5.25로 줄었고 같은 질의끼리는 +1이다.
- 범주형 질의(일반 속성 표지 8건, dev `scope=categorical`): 개입 대상 4건, 대화 16개 중 15개가 후보 밖. 리랭커로 풀리는 문제가 아니다.
- **제품 결정**: 재질문은 그대로 두고 거절 경로를 먼저 보이는 현재 UI 순서도 유지한다. 답변 질문을 더 공격적으로 낼 근거는 없다 — 같은 질의에서 틀린 답의 손해는 그대로이고, 맞는 답이 정답을 밀어내는 경우가 새로 생겼다.
